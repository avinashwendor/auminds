# AUMINDS — Product Context

## What is AUMINDS?
AUMINDS is a premium Learning Management System (LMS) platform purpose-built for coding education. It provides a complete academy experience: protected video streaming, interactive markdown documentation, an in-browser Monaco IDE with live execution, quizzes, assignment submissions with admin review, gamified leaderboards, community chat, and a curated job board.

## Who is it for?
- **Primary**: Aspiring software engineers and coding bootcamp students
- **Secondary**: Admin instructors who create and manage course curricula, grade assignments, and curate job postings

## Product Values
- **Mastery over speed**: We favor deep, thorough understanding over rushing through content
- **Professional-grade tools**: The in-browser IDE mirrors real development environments
- **Accountability**: Admin-assigned courses, graded assignments, and verified certificates
- **Community**: Peer-to-peer learning through live chat and competitive leaderboards

## Voice & Personality
- **Authoritative yet approachable**: Staff-engineer mentorship tone, not corporate jargon
- **Precise**: Technical accuracy in all copy; no filler
- **Motivating**: Celebrate progress (points, certificates, leaderboard ranks) without being patronizing

## Key User Journeys
1. **Student Login → Dashboard → Course Workspace → Complete Lessons → Earn Points → Claim Certificate**
2. **Admin Login → Create Courses/Modules/Lessons → Assign to Students → Grade Submissions → Post Jobs**
3. **Student → Community Chat → Leaderboard → Job Board → Apply**
